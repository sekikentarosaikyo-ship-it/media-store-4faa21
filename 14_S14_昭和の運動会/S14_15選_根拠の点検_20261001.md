## 正直な回答
- 事実で裏付けがあるのは、入れる理由の一部（◎の8項目）と、感情の一部（◎の5項目）だけ。
- 推測で埋めていたもの:
  1. 1件しか材料が無い項目（1・6・8・11・14）を「中」と書いて15選に入れた。
  2. 感情・共感の説明（「誇り」「自分の体験と重ねる」など）を、データの無い項目にも当てはめていた。
  3. 維持率への影響: 項目ごとのデータは1つも無い。前の版の「中盤の山」「熱さの頂点」は、コメントの高評価からの推測で、維持率の根拠ではなかった。
  4. 順番: 家族→競技→学校はせきさんの指示。編の中の順番は根拠なしで私が決めた。
- 維持率について今ある事実は、自チャンネルの別の題材のものだけ: 常識20選で「外・地域・みんなでやったこと」の項目が上がった（⑳道路が遊び場 +1.1pt、⑨名簿 +1.2pt）／「今も続く話題」が落ちた（①テレビ −4.8pt/分、⑩身体測定 −7.4pt/分）／締めの落ちが大きい（S7 −13.6pt、S5 −24.8pt）。これを運動会の各項目に当てはめるのは仮説。

## 根拠を作る方法（Mac で実行が要る）
1. 運動会の競合10本の「最も再生された部分」（YouTube の再生ヒートマップ。yt-dlp の JSON に入っている）と自動字幕を突き合わせ、どの話題で再生が山になるかを出す → 項目ごとの維持の根拠と、順番の根拠になる。
2. 自チャンネルの項目別維持率（Studio・00_共通/PDCA）を S11・S12 まで取り直す。
3. 594件のコメントで、項目ごとに感情の内訳を数え直す（サムネ担当が持っているラベル付きデータで可能）。
4. 1件しか材料が無い項目は、Mac の Chrome で生の声を集め直し、3件以上そろわなければ外す。
